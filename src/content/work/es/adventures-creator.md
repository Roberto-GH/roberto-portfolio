**Adventures Creator** es un ecosistema dise&ntilde;ado para simplificar y potenciar la creaci&oacute;n de agentes de inteligencia artificial. El n&uacute;cleo de este proyecto reside en la integraci&oacute;n del **Google ADK (Agent Development Kit)**, permitiendo orquestar comportamientos complejos y capacidades cognitivas de manera fluida.

### Arquitectura y Desarrollo

Para garantizar la escalabilidad y el mantenimiento a largo plazo, el backend se ha desarrollado utilizando **Spring Boot** bajo los principios de la **Arquitectura Hexagonal** (Puertos y Adaptadores). Este enfoque nos permite:

- **Desacoplamiento total:** La l&oacute;gica de negocio permanece aislada de las dependencias externas como bases de datos o servicios de IA espec&iacute;ficos.
- **Flexibilidad:** Facilidad para cambiar o actualizar adaptadores de infraestructura sin afectar el n&uacute;cleo del sistema.
- **Testabilidad:** Permite realizar pruebas unitarias rigurosas sobre la l&oacute;gica de creaci&oacute;n de agentes.

### Caracter&iacute;sticas Clave

- **Agentes con Google ADK:** Implementaci&oacute;n de agentes capaces de razonar y ejecutar herramientas para resolver tareas complejas.
- **Backend Robusto:** Gesti&oacute;n eficiente de estados y persistencia de configuraciones de agentes mediante servicios Spring.
- **Interfaz Intuitiva:** El frontend permite a los usuarios modelar sus "aventuras" y ver a sus agentes en acci&oacute;n en tiempo real.

Este proyecto representa la convergencia entre las mejores pr&aacute;cticas de ingenier&iacute;a de software y la vanguardia en el desarrollo de agentes de IA.
